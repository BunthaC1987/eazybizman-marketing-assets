# LinkedIn-Posts

An organized, browsable copy of each week's post batch - images plus the
matching captions/hashtags, grouped by week. Every post here ships
identically to all three connected channels (LinkedIn, Facebook, Instagram),
per the platform-parity rule in `drafts/CONTENT-STRATEGY.md`; this folder is
just named after the first channel for convenience.

This is a mirror for humans browsing brand assets, not the source of truth.
The Buffer-scheduling automation still reads the numbered PNGs at the repo
root and the captions files in `drafts/`/`published/` - nothing here is
consumed by that pipeline. When updating a caption or regenerating an image,
change it at the root/`drafts/` first, then copy the update into the
matching week folder here.
